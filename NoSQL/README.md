# MongoDB + Neo4j Exam Preparation

A practical, exam-oriented study repository covering:

- MongoDB CRUD Operations
- Search & Query Operations
- Aggregation & `$lookup`
- Import & Export
- Backup & Restore
- Replica Sets
- Array Operations
- Indexing & Performance Optimization
- Neo4j / Cypher basics, CRUD, nodes, properties and relationships

## Study order

## Requirements

- MongoDB Server + `mongosh`
- MongoDB Database Tools (`mongoimport`, `mongoexport`, `mongodump`, `mongorestore`)
- Neo4j Desktop or Neo4j Server
